# Foundations of IoT Lab

Repository for Foundations of Internet of Things laboratory assessments implemented on 8051 and STM32 platforms.

## Repository structure
- [8051](8051/README.md) — AT89S52 / 8051 experiments (CAT1–CAT7).
- [STM32](STM32/README.md) — STM32 experiments (CAT8–CAT15).

Each experiment folder contains its own README describing the available task information, platform, implementation approach, and project files. Evaluation dates and task descriptions are included only where available; missing details are intentionally omitted rather than guessed.

## Project files
- **8051:** Embedded C source, Keil µVision projects, startup assembly, HEX outputs, and circuit diagrams where present.
- **STM32:** STM32CubeMX .ioc configurations, application source under Core/, HAL drivers, Keil MDK-ARM projects, and supporting flow/configuration files where present.
